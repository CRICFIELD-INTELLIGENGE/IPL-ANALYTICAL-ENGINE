# Dugout loading repair — 26 October 2026

AdSense now waits for one shared script-loading promise, initializes each connected visible DOM slot once, cancels pending requests on unmount, and requires explicit consent. Ad and sponsor placements remain mounted independently of Getty.

Getty rendering now requires the rights gate even on localhost, including a written authorization reference for CricField commercial editorial embedding. The internal review panel accepts that evidence; the release filter withholds embeds missing it. Individual widget timeouts no longer disable all images.

The existing manifest contains 340 approved-embed records without that authorization reference. No manifest records or approval statuses were changed in this repair. These records are withheld and readers see original illustrations.

Validation: 716 image checks pass; 340 manifest checks flag missing authorization, one per record. Browser verification after the ad repair showed three initialized ad slots without console warnings. Getty viewers previously displayed broken-image text; this work does not claim Getty photo delivery or grant usage rights. No photo was downloaded or hotlinked.
