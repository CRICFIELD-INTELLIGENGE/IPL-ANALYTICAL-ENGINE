# Security Policy

## Supported Versions

Only the latest release and active branches of CRICFIELD are actively maintained with security updates.

| Version | Supported |
| :--- | :--- |
| `2.0.x` | :white_check_mark: |
| `< 2.0` | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately. Do not report security vulnerabilities through public GitHub issues.

To report a vulnerability, please contact the CRICFIELD Organization administrators or open a private GitHub security advisory at:
https://github.com/CRICFIELD-INTELLIGENGE/IPL-ANALYTICAL-ENGINE/security/advisories/new

We appreciate your responsible disclosure and will respond promptly.
